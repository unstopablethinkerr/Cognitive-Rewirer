# Cognitive Rewirer 🧠⚡

A minimalist, high-impact neuroplasticity training game built with vanilla HTML, CSS, and JavaScript. Designed to challenge **cognitive flexibility** and test your executive functioning by forcing the brain to break automatic habits in real-time.

---

## 🚀 Overview

The **Cognitive Rewirer** utilizes a variation of the famous **Stroop Effect** combined with dynamic **Task Switching**.

From childhood, our brains build heavily reinforced neural pathways for reading text. This game forces you to actively suppress those automatic pathways and fire up secondary ones by rapidly swapping the objective between matching the **word meaning** versus matching the **font color**.

---

## ✨ Features

* **Dynamic Rule Switching:** Randomly toggles between "Match the Word" and "Match the Color" rules to prevent cognitive autopilot.
* **Instant Feedback & Visuals:** Sleek cyberpunk-inspired UI with smooth color feedback, screen-shake error notifications, and glowing success states.
* **Streak & Scoring System:** Multiplier bonuses reward consistent adaptation under pressure.
* **Zero Dependencies:** Pure, lightweight, single-file vanilla JavaScript—no frameworks, npm packages, or build tools required. Just open and play.

---

## 🕹️ How to Play

1. **Observe the Rule Box:** Look closely at the top indicator to see whether the current round requires you to match the **WORD** or the **COLOR**.
2. **Analyze the Target:** Look at the large central text, paying attention to both what it spells and the color of the ink.
3. **Select Your Answer:** Click one of the four color buttons before you lose your streak!
* *If the rule is "Match the WORD":* Click the button that matches the text content.
* *If the rule is "Match the COLOR":* Click the button that matches the ink color (ignoring what the word says).

## 🛠️ Installation & Running Locally

Because this project is contained entirely in a single file, running it takes seconds:

1. Clone or download this repository:
```bash
git clone https://github.com/your-username/cognitive-rewirer.git

```


2. Navigate to the project directory:
```bash
cd cognitive-rewirer

```


3. Open the `index.html` file directly in any modern web browser (Chrome, Firefox, Safari, Edge).

## 🧬 The Science of Neuroplasticity Behind It

* **Inhibition of Automaticity:** Reading text is an automatic process. When the rule shifts to matching colors while text conflicts, your brain experiences cognitive friction.
* **Executive Control:** The prefrontal cortex must actively inhibit the stronger reading pathway and empower the weaker color-recognition pathway.
* **Synaptic Adaptation:** Rapidly changing rules challenge your working memory and foster structural plasticity through active problem-solving.
